## 最终根因与修复（13:55 完成）
- 真正根因：TabNavigation.jsx 主界面 horizontal 布局分支存在多余括号垃圾——第639行裸 `(` 包裹 Fragment、第746/747行多出孤立 `)` `}`（无匹配 `{`）。babel/parser 裸解析对含多余 `)` `}` 的文件仍返回 OK（容错），但 vite dev 的 @vitejs/plugin-react(babel/jsx) 报 `The character } is not valid inside a JSX element`，主窗口 React 渲染失败→透明空窗/进程退出。
- 修复：删除第639行裸 `(`、第746行 `)`、第747行 `}`（horizontal Fragment 尾部）。babel + esbuild 双重验证语法合法。

- 关键经验（可复用）：① vite 报 JSX 错误但 `babel/parser` 裸 parse OK → 真实差异在 @vitejs/plugin-react 工具链（缺 @babel/plugin-transform-react-jsx，jsx 转由 babel 其他路径），勿只信裸 parser；② 文件是 CRLF，Edit 工具用 LF old_string 会匹配失败，改用 node 脚本按行精确删除并 join('\r\n') 保留 CRLF；③ 文件含多个同签名标签（两个 `<>` Fragment）时，从头遍历+break 会遗漏，需倒序或全量匹配。
